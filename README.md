<h1 align="center">Selected Projects</h1>

- **Multi-Tenant Agentic AI Platform.** LangGraph agents on AWS Bedrock AgentCore serving 7 product lines, loading their tools at runtime over MCP.
- **Enterprise RAG Platform.** Retrieval on AWS S3 Vectors with Bedrock Titan v2 embeddings, one vector index per tenant.
- **AIOps Operator Console.** Six monitoring systems behind one connector SDK, with anomaly detection and root-cause ranking on top.
- **Per-Call LLM Cost Instrumentation.** Prices prompt, output, thinking and image tokens separately, per call, against a per-model rate table.
